# A4 flyer (print)

- `flyer.html?v=light&main=uber` — white version, Uber & Bolt fingerprint capture as the main service.
- `flyer.html?v=light&main=web` — white version, web & app development as the main service.
- `flyer-courses.html` — a full page only for the Adobe graphic design & video courses (white style). Prices and topics come from courses.html and the bundle calculator in js/site.js; update both together.
- `WebGraphs-A4-flyers.pdf` — all three white flyers in one file (fingerprints, web & app, courses).
- `flyer.html?v=dark` — the navy version (design A). Add `&bleed=3` for a print-shop file with 3 mm bleed.
- `WebGraphs-A4-flyer-*.pdf` — the print files (A4, 210 × 297 mm, fonts embedded, photos at ~700 ppi).

Everything (text, logo, QR) stays at least 13 mm inside the trimmed edge. Print at 100 % / "Actual size", not "Fit to page".
